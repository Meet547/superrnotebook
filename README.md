# SuperNotebook

SuperNotebook is a personal learning workspace built for people who want to think clearly, study with structure, and keep their ideas in one place. It starts as a notebook-like experience and grows into a daily tool for capturing notes, asking questions, turning ideas into study material, and sharing progress with a community.

## What we're building

We are building a calmer, more useful way to work with information.

The product combines:
- a clean notebook experience for writing and organizing thoughts
- a dashboard for learning and review
- AI-assisted help for chat, quizzes, and study workflows
- a community layer for sharing and discussion
- a foundation for future features that make learning feel more active and less scattered

## Current status

The app already includes:
- a landing experience with a notebook-inspired design
- authentication flow and protected dashboard routes
- a main dashboard structure with sections for chat, quizzes, community, library, and settings
- a frontend built with React, TypeScript, Vite, Tailwind CSS, and shadcn/ui

## Running locally

1. Install dependencies
   ```bash
   npm install
   ```
2. Start the development server
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal, usually:
   ```text
   http://localhost:8080/
   ```

## Build and test

```bash
npm run build
npm run test
```
